# Wholesale ERP — Manual Test Cases

Code-grounded positive & negative test cases for every module, including role-based access checks. Execute each against a running backend (`uvicorn` + MariaDB, `admin/Admin@1234`) and tick **Pass/Fail**.

**Totals:** 490 cases across 10 modules — 180 positive, 310 negative.

**Roles:** `super_admin` (all + role grants) · `admin` (all admin ops) · `accountant` (financial/GST/reports) · `sales` (read + create sales). Auth guards: `get_current_user` (any auth, 401 if none), `require_admin` (403 else), `require_admin_or_accountant` (403 else), `require_super_admin` (403 else).
